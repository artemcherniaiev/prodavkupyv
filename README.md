# ProdavKupyv — Веб-маркетплейс

## Опис проєкту
«ProdavKupyv» — це веб-платформа для купівлі та продажу товарів із підтримкою фіксованої ціни, торгів та модерації.

## Виконавець
Студент групи [КА-45] — [Черняєв Артем]

## Застосовані технології та верстка
- **HTML5 та CSS3** (змінні `:root`, вебшрифт `Inter`, HTML5-валідація форм і CSS-псевдокласи `:focus`, `:invalid`, `:valid`)
- **Сучасні макети й адаптивність:** `CSS Flexbox` (шапка, навігація, каркас сторінок, розкладка каталогу), `CSS Grid` (`repeat(auto-fill, minmax(260px, 1fr))` для сітки товарів) та медіазапити `@media` (`992px`, `768px`)
- **Модульна організація стилів:** поділ на `css/base.css`, `css/layout.css` та `css/components.css` з об’єднанням через `@import` у `css/style.css` (без препроцесорів)
- **JavaScript:** клієнтський скрипт `js/main.js` для керування мобільним меню

## Структура проєкту
- `index.html` — Головна сторінка з каталогом та фільтрами
- `product.html` — Картка товару з формою оферу
- `create-item.html` — Створення оголошення
- `profile.html` — Особистий кабінет користувача
- `admin.html` — Панель модерації
- `css/style.css` — Головний файл стилів (підключає модулі через `@import`)
- `css/base.css` — Змінні, шрифт і базова типографіка
- `css/layout.css` — Макет, сітки, таблиці, підвал і медіазапити
- `css/components.css` — Картки товарів, форми, стани валідації та кнопки
- `js/main.js` — Інтерфейсні скрипти
- `images/` — Графічні ресурси (логотип, фото товарів)
