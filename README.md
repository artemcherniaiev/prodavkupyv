# ProdavKupyv — Веб-маркетплейс

## Опис проєкту
«ProdavKupyv» — це веб-платформа для купівлі та продажу товарів із підтримкою фіксованої ціни, торгів та модерації.

## Виконавець

## Структура проєкту
- `index.html` — Головна сторінка з каталогом та фільтрами
- `product.html` — Картка товару з формою оферу
- `create-item.html` — Створення оголошення
- `profile.html` — Особистий кабінет користувача
- `admin.html` — Панель модерації
- `css/style.css` — Зовнішні стилі
- `js/main.js` — Інтерфейсні скрипти
- `images/` — Графічні ресурси (логотип, фото товарів)
